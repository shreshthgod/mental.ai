# Browser extension proposal

No extension is implemented or deployed. This document describes possible future work.

An extension would require explicit permission for each enabled site and each input surface. It should exclude password fields, payment forms and unsupported embedded editors. Text processing would run locally after an explicit action. Passive monitoring would require a separate informed choice.

Browser model work depends on validated artifacts, documented training-data rights, preprocessing parity and measured runtime behavior. No accuracy, latency, model-size or offline-support targets have been verified. Emotion classification must remain separate from safety guidance and diagnosis.

Raw text, embeddings and conversation histories must not be uploaded in a private mode. Any score synchronization needs separate consent, account isolation, retention limits and deletion controls. Derived mental-health scores remain sensitive.

Before implementation, validate model behavior on independent data, test unsupported languages and abstention, audit browser permissions and storage, and measure download size, memory and latency on representative devices.
